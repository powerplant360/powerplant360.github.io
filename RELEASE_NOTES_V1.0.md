# PowerPlant360 V1.0

Production baseline for the PowerPlant360 Engineering Knowledge Assistant.

## V1.0 highlights

- Login-first secure application.
- Admin / Engineer / Viewer role separation.
- Private Supabase document storage with RLS.
- Plant Data search restricted to authorized users.
- Admin-only Online Search.
- PDF, Office and image indexing.
- Vision indexing for weak/scanned PDF pages.
- Supporting PDF image preview and spreadsheet preview.
- Department document upload and screenshot paste.
- Admin User Management.
- Password recovery flow.
- API usage/cost dashboard.
- Backup export and department ZIP backup.
- Installable PWA shell with network-first updates.
- Service worker never caches private Supabase/API/document responses.
